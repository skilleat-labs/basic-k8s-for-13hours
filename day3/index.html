    3일차 · 영속성과 보안¶

    앱을 배포했으니 이제 데이터를 지키고 클러스터를 안전하게 만듭니다. Pod가 사라져도 데이터가 남도록 PV/PVC 를 붙이고, 공격자의 침입 사슬(침입→권한상승→정찰→내부이동)을 securityContext·PSA·RBAC·NetworkPolicy 로 한 단계씩 끊습니다.

    오늘의 실습¶

    # 실습 무엇을 배우나
    1 볼륨 실습 — emptyDir emptyDir 임시 볼륨·컨테이너 간 공유·Pod 삭제 시 소실
    2 볼륨 실습 — PV / PVC PV/PVC·정적·동적 프로비저닝·데이터 영속성
    3 securityContext 하드닝 root 컨테이너 위험 재현 → 방어 설정
    4 Pod Security Admission 네임스페이스 단위로 위반 Pod 거부
    5 RBAC 최소 권한 ServiceAccount·Role·RoleBinding, auth can-i
    6 토큰 마운트 차단 SA 토큰 자동 마운트 차단
    7 NetworkPolicy 전면 차단 후 선별 허용, 내부 이동 차단

    보안 실습의 색 규칙

    이 과정에서는 공격·위협은 빨강, 방어·차단은 파랑 으로 구분합니다. 실습 문서에서도 공격 재현과 방어 적용 단계를 구분해 표시합니다.
